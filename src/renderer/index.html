          ClipNinja Features & shortcuts

          Global shortcuts

          These work from any app while ClipNinja is running.

          • Open clipboard history (compact overlay) ⌘⇧V
          • Open saved templates / SavedClip ⌘⇧B
          • Quick add a todo ⌘⇧D
          • Today’s todo list (focus view) ⌥⇧D

          On the keyboard: Command+Shift+V/B/D, Option+Shift+D. If a shortcut does nothing, check System Settings → Keyboard → Keyboard Shortcuts for conflicts.

          Menu bar

          Click the ClipNinja icon in the menu bar to open:

          • Clipboard — recent clips by app group; open full UI or paste from the list.
          • SavedClip — saved templates; open full UI or paste.
          • Todos — full todo list, filters, dates, and clear completed.
          • Quick add todo — small overlay to add a task with a date.
          • Today’s todos — today-only list with add, check off, and delete.
          • Settings — theme, launch at login, clipboard/template limits.
          • Info — this screen.

          Features

          • Clipboard — history grouped by source app; arrow keys to browse; Enter pastes into the app that was focused when you opened the overlay.
          • Templates — list and configure reusable text snippets (SavedClip).
          • Todos — tasks with target dates; filter chips (All, Today, Tomorrow, Week, Month).
          • Quick add — minimal strip; Enter saves, Esc closes; clicking outside closes.
          • Today’s view — scrollable list; Esc closes; clicking outside closes.
          • Theme — System, Dark, or Light in Settings.
